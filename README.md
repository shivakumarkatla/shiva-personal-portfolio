# Shiva Kumar — Personal Brand Website

Build 01 establishes the foundation for the personal-brand portfolio.

## Stack

- React
- Vite
- React Router
- CSS design tokens
- Motion (ready for later builds)
- Lucide React (ready for later builds)

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Structure

- `src/components` — reusable UI/layout components
- `src/data` — project and skill content
- `src/pages` — route-level pages
- `src/styles` — global styles and design tokens

Build 02 will replace the placeholder home page with the full hero experience.
